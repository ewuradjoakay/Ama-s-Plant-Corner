# Ama's Plant Corner

## Project Overview

Ama's Plant Corner is a website redesign for a small neighbourhood plant shop run by Ama.

The redesign focuses on making the website feel calm, welcoming and personal, while also making it easier for customers to use on their phones.

## Project Goals

The main goals of the redesign were to:

* Make the website easier to use on mobile devices.
* Make information easier to read and find.
* Give the website a more personal and welcoming feeling.
* Help first-time plant owners feel comfortable asking questions.
* Make Ama's products, plant-care advice and contact information easy to find.

## Visual Design

The website uses mainly green and cream colours with warm accents to create a natural, calm and welcoming feeling.

Plant images, rounded cards, soft backgrounds and clear spacing were used to make the website feel friendly and connected to Ama's physical plant shop. The design was kept simple so that customers can focus on the products, advice and information without feeling overwhelmed.

## Design Approach

The layout was planned with mobile users in mind because many of Ama's customers may find the shop while using their phones.

The content is arranged so visitors can first understand the shop, explore the products, learn about Ama and her plant-care advice, and then ask questions or get in touch.

## Additional Improvement

An additional improvement was included to make it easier for first-time plant owners to ask Ama for help when they are unsure about choosing or caring for a plant.

This supports the friendly and personal experience of visiting Ama's physical shop. It also gives customers a simple way to interact with Ama instead of only viewing the products.
